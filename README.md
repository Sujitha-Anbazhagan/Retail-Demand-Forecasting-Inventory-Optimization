# Retail Demand Forecasting & Inventory Optimization

An end-to-end retail analytics platform for forecasting product demand and optimizing inventory replenishment.

## Objective

The project uses historical Walmart sales data to:

- Analyze retail demand patterns
- Forecast future product demand
- Identify inventory risks
- Calculate reorder points
- Recommend inventory replenishment quantities
- Provide interactive business insights through a Streamlit dashboard

## Tech Stack

- Python
- SQL
- Google BigQuery
- dbt
- Prophet
- LightGBM
- Pandas
- Plotly
- Streamlit

## Project Architecture

M5 Walmart Dataset
→ Python ETL
→ BigQuery
→ dbt
→ Forecasting Models
→ Inventory Optimization
→ Streamlit Dashboard
